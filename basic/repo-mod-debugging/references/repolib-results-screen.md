# R.E.P.O. 0.5.2 и сбой на экране итогов

**Симптом.** Переход с экрана результатов срывался. Одна ошибка сохранения повторилась 2 465 раз.

**Причина.** Действительно загруженная REPOLib 4.5.0 ссылалась на `MetaManager.VerifySaveFile` и `MetaManager.DeleteSaveFile`. Сравнение с установленной сборкой R.E.P.O. 0.5.2 показало, что этих методов там уже нет. Проверка установленных DLL указала на вызывающую библиотеку.

**Проверка исправления.** В сохранённых логах установки с REPOLib 4.5.1 эти ошибки исчезли. Это наблюдение про конкретное сочетание версий и этот стек вызовов. Для другой установки сверь фактическую версию загрузки и повтори экран итогов в изолированном профиле.

Полезный отчёт содержит окно исходной ошибки, сигнатуру, имя вызывающей DLL, версию игры и результат с исправленной зависимостью. Сырые пользовательские логи можно оставить локально.
