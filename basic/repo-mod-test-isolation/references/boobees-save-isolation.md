# Boobees Valuables и сохранения

**Симптом.** После ранних приватных запусков в сохранении владельца пропали разблокированные косметические предметы. Снимки сузили эпизод до нескольких запусков. Точный первый повредивший запуск не установлен.

**Причина.** Перенаправление охватывало вызовы самой игры. Приватный `MetaManager` загрузил пустое состояние, а код `REPOLib` затем записал пустые списки в основной файл через оставшиеся общие пути.

**Исправление.** До старта плагинов в тестовом процессе перенаправили `Application.persistentDataPath` и проверили перенаправление всех 13 публичных методов `PlayerPrefs` для этой версии Unity. Игровые и сторонние DLL на диске остались прежними. При восстановлении затронули только поля `cosmeticUnlocks` и `cosmeticHistory` в штатном сохранении после разрешения владельца.

**Проверка.** Фактический игровой smoke-тест загрузил и записал приватные ES3/REPOLib данные, завершился с кодом 0 и оставил 82 проверенных исходных файла побайтно неизменными. После последующей записи игры в обычном профиле 173 восстановленных предмета сохранились.

В новом проекте сверяй реальный путь записи каждого участвующего плагина и проверяй ожидаемый результат записи в приватной копии. Состав файлов и число ключей определяются установленным набором модов.
