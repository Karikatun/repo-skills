Версию Unity и пакета AI Navigation сверяйте с целевой установкой. Например, инструкция по `NavMeshSurface` относится к подходящему пакету Unity Editor, а мод в установленной игре использует уже загруженную геометрию и API игры.

Для дверей, погони и столкновений в сгенерированной комнате см. [движение монстра](../monsters/repo-mod-monster-movement/SKILL.md). Для проверки точного пакета в игре см. [приёмку](../monsters/repo-mod-acceptance/SKILL.md).
