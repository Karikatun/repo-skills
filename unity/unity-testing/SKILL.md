# Проверка поведения в Unity

1. Определи наблюдаемый результат и условия, в которых проявляется ошибка. Сверь версию редактора и установленный Unity Test Framework. Используй действующую тестовую сборку проекта, если она подходит.
2. Для чистой логики и редакторских API начни с Edit Mode. Для жизненного цикла компонентов, загрузки сцены и физического взаимодействия выбери Play Mode. Обычный синхронный случай покрывает `[Test]`. Если проверка ждёт кадр или шаг физики, используй `[UnityTest]` и подходящее условие завершения.
3. Выполни узкую проверку через **Window → General → Test Runner** или команду проекта. При исправлении регрессии воспроизведи отказ и повтори тот же тест после изменения. Убери созданные объекты и восстанови изменённое состояние.
4. Проверь режим, имя выполненного теста, результат и ошибки журнала. Для CLI сверь код выхода и свежий XML с ненулевым числом выбранных тестов. Если сценарий зависит от целевого Player, сборки игры или второго клиента, проверь его в соответствующей среде и укажи её в результате.
